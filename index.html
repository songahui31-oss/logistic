로지스틱 회귀: 범주를 예측하는 분류 모델

활동지 빈칸 암기 모드

가려진 핵심 키워드를 클릭해서 정답을 확인해 보세요!

1. 두 가지 중 하나로 예측하면 이진 분류, 세 가지 이상의 범주 중 하나로 예측하면 다중 분류이다.

2. 로지스틱 회귀는 선형 결합식 z = ax + b 의 결과를 로지스틱 함수에 넣어 0과 1 사이의 확률로 변환한다.

3. 이진 분류에는 시그모이드(Sigmoid) 함수를 쓰며, 입력값 z=0일 때 출력값은 0.5이다.

4. 다중 분류에는 소프트맥스(Softmax) 함수를 쓰며, 모든 범주의 출력 확률 합은 항상 1이다.

5. 스팸 메일 분류처럼 정상 메일을 스팸으로 잘못 거르는(FP) 것을 줄이려면 정밀도(Precision)가 중요하고, 코로나19 감염자를 놓치지 않으려면(FN 최소화) 재현율(Recall)이 중요하다.

1부 로지스틱 회귀와 분류 모델
  • 선형 회귀 vs 분류: 연속적인 수치 예측은 선형 회귀, 범주(클래스) 예측은 분류 사용.
  • 직선만 쓰지 않는 이유: 직선 방정식은 음수나 1보다 큰 값이 나와 확률(0~1)로 쓸 수 없음.
  • 드라마 데이터 전처리: 8개 장르 중 표본이 적거나 특징이 불분명한 장르를 제외하고 미니시리즈, 일일연속극, 주말연속극 3개만 선택.
2부 분류 모델의 평가 지표
  • 오분류표(Confusion Matrix): TP(진짜 양성), FN(놓친 양성), FP(잘못된 양성 예측), TN(진짜 음성).
  • 정확도의 함정: 미니시리즈가 60%를 차지해 무조건 미니시리즈로 찍어도 정확도가 60% 나옴.
  • 불균형 데이터 평가: 클래스별 정밀도, 재현율, F1-score(macro avg)를 함께 확인해야 함.

교과서 핵심 파이썬(Scikit-Learn) 코드 요약

# 1. 데이터 필터링 및 훈련/테스트 분할 (기본 test_size=0.25)
top = df[df.genre.isin(['일일연속극', '미니시리즈', '주말연속극'])]
X = top.iloc[:, 1:]   # 14개 성별·연령대별 시청률
y = top['genre']      # 종속 변수(레이블)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=10)

# 2. 로지스틱 회귀 모델 학습 및 예측
from sklearn.linear_model import LogisticRegression
LR = LogisticRegression()
LR.fit(X_train, y_train)
LR.predict([X_test.iloc[0]])  # 2차원 입력을 위해 대괄호로 감싸기!

# 3. 오분류표 및 평가 지표 출력
from sklearn.metrics import confusion_matrix, accuracy_score, classification_report
print(confusion_matrix(y_test, LR.predict(X_test)))
print(accuracy_score(y_test, LR.predict(X_test)))
print(classification_report(y_test, LR.predict(X_test)))
